# Team Member Abbreviations

This steering file provides mappings for team member abbreviations used throughout specs and documentation.

## Team Members

| Abbreviation | Full Name |
|---|---|
| Vip | Viprannan |
| Vis | Vishnu |
| A | Ashwin |
| C | CSP |
| Va | Varun |

## Usage

When team member abbreviations are mentioned with "Teams" context, they should be expanded to their full names:
- **Vip** → Viprannan
- **Vis** → Vishnu
- **A** → Ashwin
- **C** → CSP
- **Va** → Varun

Example: "Teams: Vip, Vis, A" should be understood as "Teams: Viprannan, Vishnu, Ashwin"

## Documentation Rules

- Never add any new .md/.txt files for documentation
- All documentation updates must be made to README.md
- Keep the repository clean by consolidating all docs in one place
