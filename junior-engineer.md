## About Kactii

Kactii is a Canadian startup specializing in the development of advanced Generative AI agents for funded startups and SMEs across North America, India, and the Philippines. We build automation systems, AI copilots, and intelligent workflows that improve productivity and operational efficiency for modern businesses.

We are expanding our engineering team with junior engineers who have strong frontend skills and are eager to work at the intersection of UI engineering and Generative AI systems.

---

## Role Overview

The **Junior Software / GenAI Engineer** will work across two key domains:

1. **Frontend Engineering** – Building clean, responsive, and intuitive dashboards, agent configuration panels, and client-facing UI components using React.js, Tailwind CSS, HTML/CSS, and modern frontend tooling.

2. **GenAI Agent Development** – Supporting the development and integration of AI agents using Python/Node.js, LLM frameworks, and vector-based retrieval systems.

This is an ideal role for fresh graduates who want to combine UI engineering with AI system development.

---

## Key Responsibilities

### 1. Frontend/UI Development

* Build responsive web interfaces using **React.js**, **HTML**, **CSS**, **Tailwind CSS**, and related modern libraries.
* Implement reusable UI components and maintain a consistent design system.
* Optimize frontend performance, load times, accessibility, and user experience.
* Work closely with designers and backend engineers to connect UI with backend APIs and AI workflows.

### 2. GenAI Agent Development (Foundational Responsibilities)

* Assist in building AI agent workflows using LangChain, LangGraph, or custom libraries.
* Implement prompt templates, RAG modules, and logic for multi-step reasoning tasks.
* Support backend services connecting the UI to AI agents.
* Conduct testing, debugging, and iterative refinement of AI-driven features.

### 3. API & Backend Integration

* Integrate REST APIs, WebSockets, and internal endpoints with the frontend.
* Understand and handle data flow between the UI and AI agent orchestration engine.
* Work with Python/Node.js microservices when necessary.

### 4. Testing, Monitoring & Documentation

* Perform functional testing of UI components and AI-driven features.
* Debug and resolve UI and integration issues across the stack.
* Document UI components, API contracts, prompt workflows, and architecture diagrams.
