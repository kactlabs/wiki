# Junior Software / GenAI Engineer

**Location:** Remote (Tamil Nadu)
**Company:** Kactii (Canadian Startup)
**Eligibility:** Fresh Graduates Welcome
**Equipment:** Must have personal laptop + stable high-speed internet; MacBook provided after 3-month probation
**Domain:** GenAI Agents for funded startups & SMEs in North America, India, and the Philippines

---

## Role Overview

The Junior Software/GenAI Engineer will contribute to the development, testing, and deployment of AI-driven agents built for real-world automation use cases. This role involves working with LLMs, prompt engineering, workflow automation, data pipelines, and backend engineering. You will collaborate with senior engineers to build scalable, production-grade AI agents used by global startup clients.

---

## Key Responsibilities

### 1. GenAI Agent Development

* Assist in designing, building, and refining GenAI agents using frameworks such as LangChain, LangGraph, and custom Python tooling.
* Implement prompt templates, retrieval workflows, and chain/graph logic to support multi-step reasoning tasks.
* Build and test automation logic that integrates LLM-driven decisions with external APIs, tools, or databases.
* Conduct model evaluations, prompt tuning, and structured testing to improve agent accuracy and reliability.

### 2. Backend Engineering & Integrations

* Develop lightweight backend services in Python/Node.js to host and orchestrate agents.
* Integrate third-party APIs (Slack, Gmail, CRM systems, Notion, internal tools, etc.) into agent workflows.
* Work with vector databases (FAISS, Qdrant, Pinecone, Weaviate) for embedding-based retrieval.

### 3. Data Processing & Pipeline Support

* Clean, prepare, and transform unstructured datasets to support agent context and reasoning.
* Build ingestion jobs for documents, web data, or structured sources.
* Run quality checks and ensure data integrity for agent performance.

### 4. Testing, Evaluation & Monitoring

* Perform unit, functional, and regression testing of AI agents.
* Instrument agents with logging/telemetry tools (LangFuse, OpenTelemetry, custom logs).
* Help diagnose and resolve production bugs, failure modes, and performance bottlenecks.

### 5. Collaboration & Documentation

* Work closely with senior engineers to implement features, design components, and improve agent performance.
* Participate in daily stand-ups, sprint planning, and code reviews.
* Document prompts, workflows, APIs, and implementation details in a clean, maintainable manner.
