## ✅ Logo Deliverables – File Formats & Sizes

### 📁 **File Formats to Provide**

| Format              | Purpose                                                          |
| ------------------- | ---------------------------------------------------------------- |
| **.SVG**            | Scalable vector for web and apps                                 |
| **.EPS**            | Vector for professional printing (business cards, banners, etc.) |
| **.AI**             | Adobe Illustrator source file for future edits                   |
| **.PDF**            | High-resolution print-ready version                              |
| **.PNG**            | Transparent background for websites and presentations            |
| **.JPG / JPEG**     | Compressed version for standard digital use                      |
| **.ICO** (optional) | Favicon for website tab icon                                     |

---

### 📏 **Sizes to Provide**

#### 🔹 **Vector Files (SVG, EPS, AI)**

* Resolution-independent – no need for multiple sizes

#### 🔹 **Raster Files (PNG, JPG)**

Provide in the following sizes:

* **500x500 px** – for general web use
* **1080x1080 px** – ideal for social media (Instagram, etc.)
* **1920x1080 px** – for presentations and banners
* **3000+ px** – high-resolution print version

#### 🔹 **Favicon Sizes (Optional)**

* 16x16 px
* 32x32 px
* 48x48 px

---

### 🎨 **Color Variations**

Please include:

* ✅ Full color version
* ✅ Black on white background
* ✅ White on black background
* ✅ Transparent background version
