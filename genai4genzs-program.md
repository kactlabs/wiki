### How It Works

**Vibe Coding (70% of the program)**

You talk to AI, AI writes the code. You're the boss.

- Describe what you want in plain English
- AI generates the code
- You review, tweak, and ship it
- Tools: Kiro.dev, GitHub Copilot, KiloCode CLI, Cline

**Manual Coding (30% of the program)**

You write the code yourself. This is where you level up for real.

- Python basics — variables, loops, functions
- Simple AI scripts — make a chatbot from scratch
- Fix bugs that AI creates (yes, AI makes mistakes too)
- Understand what's happening under the hood

### Program Chapters

**Chapter 1: AI is Your New Superpower**
Meet AI tools that can write code, make art, and answer anything. Set up your workspace. Build your first AI project in 10 minutes using vibe coding.

**Chapter 2: Python — The Language AI Speaks**
Learn Python basics the fun way. Variables, loops, lists, and functions. Just enough manual coding so you know what AI is doing when it writes code for you.

**Chapter 3: Vibe Coding with Kiro, Copilot & Cline**
Use Kiro.dev and GitHub Copilot to build apps by just describing them. Use Cline and KiloCode CLI to generate code from prompts. Ship 3 mini projects this week.

**Chapter 4: Chatbots & Conversations**
Build your own chatbot using GenAI APIs. Give it a personality. Make it funny, smart, or weird. Deploy it so your friends can talk to it.

**Chapter 5: AI Art, Music & Content**
Use AI to generate images, music, and stories. Build a creative project — maybe an AI comic book or a song generator. Combine multiple AI tools together.

**Chapter 6: Build a Real Website with AI**
Use vibe coding to build a full website with Bootstrap. Add AI features using FastAPI backend and MongoDB. Deploy to Vercel — your project is now live on the internet for anyone to see.

**Chapter 7: Azure Cloud — Level Up Your Deployment**
Learn what "the cloud" actually means. Deploy your AI project to Microsoft Azure. Now you're running code on real servers like a pro engineer.

**Chapter 8: APIs & Backend with FastAPI + MongoDB**
Learn how apps talk to each other using FastAPI. Store data in MongoDB. Build a monolithic app that pulls live data and does something cool with AI. Connect tools using MCP.

**Chapter 9: Team Projects & Collaboration**
Work with other juniors to build something bigger. Use GitHub to share code. Learn how real dev teams ship products together.

**Chapter 10: Ship Your Portfolio**
Package everything you've built into a portfolio website. Write about what you learned. Show it off to family, friends, and future schools.
